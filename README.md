# Animated Login & Sign Up Form UI

A modern, responsive Login and Sign Up Form UI built using HTML, CSS, and JavaScript.

## ✨ Features

- Modern neumorphic UI design
- Responsive layout
- Smooth Login and Sign Up animations
- Show/Hide password functionality
- Form validation
- Password confirmation validation
- Light and dark theme support
- Animated input focus effects
- Interactive buttons and hover effects

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts (Poppins)

## 📁 Project Structure

```text
animated-login-signup-ui/
├── index.html
├── style.css
├── script.js
└── README.md
```

## 🚀 How to Use

1. Download the ZIP file from this repository.
2. Extract the ZIP file on your computer.
3. Open the project folder in Visual Studio Code.
4. Open `index.html` in your browser.

You can also use the Live Server extension in VS Code for live preview.

## 🎨 Customization

- Edit `index.html` to change the form structure and text.
- Edit `style.css` to customize colors, layouts, and animations.
- Edit `script.js` to modify form switching, password visibility, and validation.

## ⚠️ Important Note

This project is a front-end UI demonstration only. It does not connect to a backend or database. The login and signup success messages are demonstrations only and do not provide real authentication or account creation.
